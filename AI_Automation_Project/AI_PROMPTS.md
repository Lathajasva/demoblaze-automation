# AI-Assisted Engineering Evidence

## Project
DemoBlaze eCommerce Testing Capstone

## AI Tool Used
ChatGPT

## Purpose
AI was used as an engineering assistant to support test scenario generation, automation ideas, code review, and validation.

## Human Validation
All AI-assisted suggestions were reviewed and validated by the tester before being included in the project.

## AI Prompt 1 – Test Scenario Generation
Generate functional test scenarios for the DemoBlaze eCommerce application covering login, product search, product details, cart, checkout, and logout.

## AI Prompt 2 – Playwright Automation Support
Suggest a maintainable Playwright Java automation approach using Page Object Model, Maven, and TestNG for the DemoBlaze application.

## AI Prompt 3 – API Testing
Suggest API test cases for the DemoBlaze application using Java HttpClient and TestNG.

## AI Prompt 4 – CI/CD
Suggest a GitHub Actions workflow for running Maven-based automated tests using Java 21.

## Human Review
The generated suggestions were reviewed against the actual DemoBlaze application. Selective suggestions were implemented only after manual validation.

## Validation Principle
AI-generated content was treated as assistance only. Final test cases, automation code, API tests, and CI/CD configuration were reviewed and executed by the tester.
